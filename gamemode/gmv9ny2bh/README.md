# 五子棋对弈（gmv9ny2bh）

15×15 房间制对局，服务端权威判定。除两人联机外，支持**人机对战**：AI 棋手坐在白座，
你一个人也能下。

## 玩法

- 启动器里启动本游戏 → 「进入大厅」
- **人机对战（AI 执白）**：点第一个按钮，房间一建好 AI 就在白座上，你执黑先走
- **和朋友开黑**：创建房间拿 4 位房间码，或输对方的码加入
- 一局结束后点「再来一局」会**交换先后手**，此时 AI 若轮到执黑，会立刻自己走第一步

## AI 是怎么接进来的

AI 走的是**和真人完全一样的通道**：它就是一个 `Player`，占用房间的一个座位，
落点通过同一个 `putStone()` 判定、同一套 `checkWin()` 判胜负。
区别只有一点——它的落点由 `GomokuAI.think()` 算，而不是浏览器上报。

这样带来三个好处：

1. **协议零改动**：客户端分辨不出对面是人还是 AI，联机那条路径一行没动（回归测试 36 项全过）；
2. **天然权威**：AI 在服务端思考，客户端改不了它的棋；
3. **可复用**：AI 对 AI 就是两个座位都是 bot，直接能跑自动对战统计。

```
浏览器 ──POST /api/gmv9ny2bh/sync  act=place&x&y──┐
                                                  ├─→ GomokuWorld.place()
GomokuAI.think() ──落点 x,y──→ botTurn() ─────────┘        └→ putStone() → checkWin()
```

## 算法

**Negamax + Alpha-Beta 剪枝 + 迭代加深**，代码在 `server/GomokuAI.java`（约 600 行，无第三方依赖）。

| 组成部分 | 做法 | 为什么 |
|:--|:--|:--|
| 搜索 | Negamax（minimax 的等价写法，每层取负） | 五子棋是完全信息零和博弈，双方最优 → 反向归纳出当前最优着 |
| 剪枝 | Alpha-Beta，理想情况只需开方量级的节点 | 分支因子 200，裸搜 6 层是 200⁶，不剪根本算不完 |
| 候选点 | 只取已有棋子 **2 格内**的空位，按「我方棋型分 + 对方棋型分」降序取前 8~12 个 | 远端空格没有价值；排序越好，剪枝越早发生 |
| 评估 | **连段分**（连子数 + 开放端）为主 + **5 窗口分**为辅，72 条线（15 横 + 15 竖 + 42 斜） | 只数窗口分不出活三/死三；只数连段看不见含空隙的棋型（X_XX），两者互补 |
| 时间控制 | 迭代加深，每层算完检查剩余预算，超时丢弃本层、沿用上一层结论 | 保证每步都有答案，且难局会自动想得久一点 |
| 战术快路 | ① 能成五立即走 ② 对手能成五则只搜封堵点 ③ 盘上两子以内走启发式规则 | 省掉大量无意义的搜索；开局没有棋型可算，搜得越深越容易挑出怪点 |

### 关键踩坑（都记录在这，避免重犯）

1. **根节点试走没维护增量状态**：搜索时 `nbr`（邻域计数）和 `lineStones`（线非空标记）
   没跟着 make/unmake 更新，导致子树看不到新落子附近的应对点、叶子评估还会把
   整条线跳过 → **深搜反而比浅搜弱**（深度 4 输给深度 2）。修好后深度 4 对深度 2 胜率 80%。
2. **评估函数分不出活三**：只用 5 窗口计数时，"三颗两头空"和"三颗两头堵"分数一样，
   AI 只会堵不会杀 → 两个 AI 能互相封满 225 手不分胜负。改成连段 + 开放端打分后，
   对局能正常分出胜负。
3. **开局深搜出怪着**：盘上只有 1~2 颗子时，任何深度的评估都在放大噪声
   （实测深度 6 会走跳着的 `(7,9)`，深度 4 才走正常的 `(8,8)`）。加一条
   「两子以内走启发式最优点」的规则后，开局稳定落在对手附近。

## 已知限制

1. **AI 在锁内思考**：`GomokuWorld` 的对外方法全部 `synchronized`，AI 思考的
   26~112 ms 里整个世界（包括别的房间）都在等。把思考挪到锁外、或用按房间的细粒度锁
   才能做到真正并发。
2. **每步固定预算、不设下限**：所以 AI 有时快得不像在思考（0 ms）。想更像人，
   可以在 `botTurn` 里加一个最小延迟。
3. **没有置换表**：同一局面在迭代加深中会被重复搜索。加 Zobrist 哈希 + TT
   可以用同样的时间多搜 1~2 层。
4. **评估是静态的**：没有 VCF/VCT 这类专门找连续冲四的搜索，遇到复杂杀棋会漏。
5. **AI 只能执白**：想让它先手，靠「再来一局」交换，或改 `createRoom` 里的座位分配。
