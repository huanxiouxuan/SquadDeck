================================================
 SquadDeck  —— 地址怎么填
================================================
最省事的方法：问ai（选择工作区在当前文件夹）
	帮我查一下现在能发给朋友的联机地址，现场查 /api/net
================================================
【推荐：用 Radmin VPN 互相连（跨网络最稳）】
================================================

  前提：两台电脑都装了 Radmin VPN，且加入了“同一个”网络。

  让对方电脑打开：
        http://26.242.181.68:8080/

  (26.242.181.68 是作者这台电脑在 Radmin VPN 里的地址，而你要将这个地址用你vpn名字下的地址替换）

================================================
【用“热点”连（没有路由器、没有网线时最省事）】
================================================

热点分两种情况，填的地址不一样，先看清楚是哪种：

------------------------------------------------
情况一：你这台电脑开热点，别人连你的热点
------------------------------------------------

  Windows 设置 -> 网络和 Internet -> 移动热点 -> 打开。

  这时别人（手机/电脑）连上你开的这个热点后，在浏览器里输入：

        http://192.168.137.1:8080/

  ★ 192.168.137.1 是 Windows 移动热点固定不变的地址，不用去查，
    照抄即可（极少数情况若不是这个数，就看你连上热点后在
    命令行敲 ipconfig，找“无线局域网适配器 本地连接* N”那一栏的 IPv4 地址）。

  优点：不需要路由器、不需要网线、不需要 Radmin，只要有无线网卡就行。
  注意：连你热点的人会走你的网络（如果开了“共享网络连接”会耗你的流量）。

------------------------------------------------
情况二：大家都连同一个手机热点
------------------------------------------------

  比如都用手机开热点，你和别人都连这个手机热点。

  这时填的不是 192.168.137.1，而是“你这台电脑连上热点后拿到的地址”。
  在你这台电脑上打开命令行，敲：

        ipconfig

  找“无线局域网适配器 WLAN”那一栏的“IPv4 地址”，通常是：
        Android 手机热点：  192.168.43.x   或者 192.168.x.x
        iPhone  个人热点：  172.20.10.x

  然后别人在浏览器里输入：
        http://你查到的那个地址:8080/
        例如：http://172.20.10.2:8080/

  更省事：在你自己电脑的浏览器里打开
        http://127.0.0.1:8080/api/net
  看返回的 addrs 列表——哪个是热点网段的（通常是 192.168.x.x / 172.20.x.x）就用哪个。

------------------------------------------------
两种情况都要注意
------------------------------------------------

  1. 第一次别人连不上，多半是 Windows 防火墙拦了 Java。
     在弹“是否允许访问网络”时选“允许”；
     或者右键“以管理员身份运行”项目里的  开放防火墙8080.bat  。
  2. 热点没连上前，那张网卡是“媒体已断开连接”，地址不会出现，
     也不会被服务器打印出来——先确认别人已经连上热点。
  3. 手机热点有可能限制“设备间互访”（部分安卓机型默认隔离），
     如果 ping 得通但打不开网页，优先试“情况一（电脑自己开热点）”。


【地址从哪里看（实时，推荐）】
  在你自己电脑的浏览器里打开：
        http://127.0.0.1:8080/api/net

  返回的 JSON 里 addrs 列出的每条 url，都可以发给别人。
  它是每次打开时现场枚举网卡得到的——IP 变了，刷新一下就是最新值，
  不会像启动横幅那样给你一份过期快照。


【还是连不上？按顺序查】
  1. 服务器黑窗口必须开着。关掉窗口 = 服务器停了，谁都能连不上。
  2. 对方打开的是不是“你这台电脑”的地址（不是 127.0.0.1）。
  3. 对方电脑上先 ping 一下该地址：
         ping 26.242.181.68
     通则说明网络没问题；不通就是网络/Radmin 没连上。
  4. 确认对方 Radmin VPN 里加入的网络，和你是同一个。
  5. 走热点的话，看清楚是哪种情况：
       · 你电脑开热点 -> 填 http://192.168.137.1:8080/
       · 大家连同一个手机热点 -> 填"你这台电脑"在热点里的地址（ipconfig 查，或看 /api/net）
  6. 以上都不行，就用 Radmin VPN（最稳，不受客户端隔离/热点隔离影响）。
